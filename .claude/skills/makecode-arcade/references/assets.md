# Assets Reference

MakeCode Arcade has a half-text, half-opaque asset pipeline. Some assets can be authored as TypeScript literals; others live in autogenerated `.g.jres` files and must round-trip through the web editor.

## The 16-color default palette

Source: https://arcade.makecode.com/developer/images. *"Images in arcade are stored using 4 bits per color. The color 0 is reserved for transparency."*

| Index | Hex | Char in `` img`...` `` | Name |
|---|---|---|---|
| 0  | (transparent) | `.` | Transparent |
| 1  | `#ffffff` | `1` | White |
| 2  | `#ff2121` | `2` | Red |
| 3  | `#ff93c4` | `3` | Pink |
| 4  | `#ff8135` | `4` | Orange |
| 5  | `#fff609` | `5` | Yellow |
| 6  | `#249ca3` | `6` | Teal |
| 7  | `#78dc52` | `7` | Green |
| 8  | `#003fad` | `8` | Blue |
| 9  | `#87f2ff` | `9` | Light blue |
| 10 | `#8e2ec4` | `a` | Purple |
| 11 | `#a4839f` | `b` | Light purple |
| 12 | `#5c406c` | `c` | Dark purple |
| 13 | `#e5cdc4` | `d` | Tan |
| 14 | `#91463d` | `e` | Brown |
| 15 | `#000000` | `f` | Black |

Hex chars are case-insensitive; lowercase is conventional. To override the palette, set `palette` in `pxt.json` (index 0 must remain transparent).

## `` img`...` `` — image literal

One of the eight allowed tagged templates. Each character is a pixel; rows separated by whitespace. Author small sprites by hand.

```typescript
let player = img`
    . . . f f f f . . . .
    . . f e e e e f f . .
    . f f 4 e e e f f f f
    f f 4 4 4 e e f f f f
    f 4 4 4 4 4 e 4 f f 4
    4 d d d d d 4 e f . 4
    . 4 4 4 4 4 4 e f . .
    . . f f f f f f . . .
`
```

Runtime image APIs:

```typescript
let img1 = image.create(16, 16)
img1.fill(2)                                    // fill with red
img1.setPixel(0, 0, 1)
let c = img1.getPixel(5, 3)
img1.fillRect(2, 2, 4, 4, 5)
img1.drawLine(0, 0, 15, 15, 8)
img1.print("HI", 2, 4, 1, image.font5)
img1.flipX(); img1.flipY()
img1.replace(2, 7)                              // recolor all red pixels green
let scaled = img1.scaled(2)                     // 2x nearest-neighbor
let copy = img1.clone()
```

## `` tilemap`name` `` — tilemap reference

This tag resolves a tilemap **by resource name** — the actual data lives in `tilemap.g.jres`. The string between backticks is an ID, not literal tile data.

```typescript
tiles.setCurrentTilemap(tilemap`level1`)        // or assets.tilemap`level1`
```

Both `tiles.setTilemap` and `tiles.setCurrentTilemap` work; the latter is the canonical name.

## `` assets.image\`name\``, `` assets.tile\`name\`` `` etc.

Look up an asset by display name from the autogenerated namespace:

```typescript
let coin = sprites.create(assets.image`coin`, SpriteKind.Coin)
scene.setBackgroundImage(assets.image`title_bg`)
tiles.setCurrentTilemap(assets.tilemap`level1`)
animation.runImageAnimation(player, assets.animation`walk_right`, 100, true)
music.play(music.createSong(assets.song`boss_theme`), music.PlaybackMode.InBackground)
```

The compiler resolves these against the `.g.ts`/`.g.jres` pair. The pair is autogenerated; never edit it by hand.

## Tile APIs

```typescript
tiles.setCurrentTilemap(tilemap`level1`)
tiles.setTileAt(tiles.getTileLocation(col, row), assets.tile`myTile`)
tiles.setWallAt(tiles.getTileLocation(col, row), true)
tiles.placeOnTile(sprite, tiles.getTileLocation(col, row))
tiles.placeOnRandomTile(sprite, assets.tile`grass`)
let doors = tiles.getTilesByType(assets.tile`door`)
let isWall = tiles.tileAtLocationIsWall(loc)

scene.onOverlapTile(SpriteKind.Player, assets.tile`coin`, (sprite, location) => {
    location.tile = assets.tile`floor`         // can also write: tiles.setTileAt(location, …)
    info.changeScoreBy(1)
})
scene.onHitWall(SpriteKind.Player, (sprite, location) => {
    scene.cameraShake(2, 200)
})

let loc = sprite.tilemapLocation()
let right = loc.getNeighboringLocation(CollisionDirection.Right)
// loc has: .column .row .x .y .left .right .top .bottom
```

## The `.g.jres` file format (opaque, do not hand-edit)

JSON object keyed by asset ID. Each entry has `data` (base64), `mimeType`, optionally `displayName`/`tilemapTile`. Always ends with a `"*"` wildcard entry defining the namespace.

```json
{
    "image1": {
        "data": "hwQQABAAAAA...==",
        "mimeType": "image/x-mkcd-f4",
        "displayName": "plrfront"
    },
    "image2": {
        "data": "hwQQABAA...AA==",
        "mimeType": "image/x-mkcd-f4",
        "displayName": "grass2"
    },
    "*": {
        "mimeType": "image/x-mkcd-f4",
        "dataEncoding": "base64",
        "namespace": "myImages"
    }
}
```

Mime types seen:
- `image/x-mkcd-f4` — 4-bit-per-pixel image (sprites, tile images, animation frames). Base64 with header `0x87` + dimensions + packed pixels.
- `application/mkcd-tilemap` — tilemap layout data.
- `application/mkcd-song` — modern music editor song data.

**You cannot meaningfully hand-edit base64 image data.** The fast path is to author as `` img`...` `` literals in `.ts` files; round-trip through the web editor only when the user needs the asset editor UI.

## `.g.ts` shim (autogenerated, do not edit)

Co-generated next to each `.g.jres`. Declares a namespace whose names match the asset display names so `assets.image`coin`` resolves at compile time:

```typescript
// Auto-generated code. Do not edit.
namespace myImages {
    helpers._registerFactory("image", function(name: string) {
        switch(helpers.stringTrim(name)) {
            case "plrfront":
            case "image1": return img`...`;
            // ...
        }
        return null;
    })
}
// Auto-generated code. Do not edit.
```

Regenerated every time the asset editor saves. Any hand-edit is destroyed.

## `assets.json`

The asset editor's metadata index. Maps user-visible names → internal IDs and types. Both the web editor and the VS Code MakeCode extension read it. **Schema is undocumented.** Hand-editing is technically possible but error-prone; round-trip through the web editor for renames.

## Animations

```typescript
// One-shot
animation.runImageAnimation(sprite, [img`...`, img`...`, img`...`], 100, true)

// Stateful — multiple animations on one sprite
enum ActionKind { Idle, Walking, Jumping }
let walk = animation.createAnimation(ActionKind.Walking, 200)
walk.addAnimationFrame(img`...`)
walk.addAnimationFrame(img`...`)
animation.attachAnimation(sprite, walk)
animation.setAction(sprite, ActionKind.Walking)
animation.stopAnimation(animation.AnimationTypes.All, sprite)
```

Frame arrays from the asset editor: `assets.animation`name``. The extension `microsoft/arcade-character-animations` adds rule-based animations (e.g. "Moving + Facing Right + On Ground" → walk_right) if needed.

## Music and sounds

Two APIs, both supported:

### Modern song (Music Editor)

```typescript
music.play(music.createSong(assets.song`bgm`), music.PlaybackMode.LoopingInBackground)
```

Song hex blobs in `music.g.jres` are opaque. Use the web editor's music editor.

### Older melody / SFX

```typescript
music.playMelody("C5 G B C5 - C5 G B C5", 200)
music.playTone(Note.C5, BeatFraction.Half)
let s = music.createSoundEffect(WaveShape.Square, 5000, 200, 255, 0, 250,
                                SoundExpressionEffect.None, InterpolationCurve.Linear)
music.playSoundEffect(s, SoundExpressionPlayMode.UntilDone)
music.play(music.tonePlayable(440, 250), music.PlaybackMode.InBackground)
music.play(music.stringPlayable("C D E F G", 120), music.PlaybackMode.UntilDone)
music.stopAllSounds()
music.setVolume(128)                            // 0..255
```

Melody DSL examples: `"A5:2-120"` = note A in octave 5, 2 beats, tempo 120 BPM.

**Audio capacity** (verbatim from https://arcade.makecode.com/developer/sound):

> *"The arcade 'hardware' has three available music 'channels' that are mixed to produce the game audio … Attempting to play too many sounds simultaneously will cause some sounds to be dropped if all channels are currently busy."*

So design SFX to not all fire simultaneously, and pick playback modes carefully.

## When to hand-edit vs. round-trip through the web editor

| Asset | Hand-edit as `` img`...` `` literal? | Hand-edit `.g.jres`? | Use web editor? |
|---|---|---|---|
| Single 16×16 sprite | ✅ Easy | ❌ Base64 | Best for larger |
| Large background (160×120) | ⚠ Painful but possible | ❌ | ✅ |
| Animation frame list (≤4 frames) | ✅ Array of `` img`...` `` | ❌ | ✅ for longer |
| Tilemap (any size) | ❌ | ❌ | ✅ Mandatory |
| Song / music | ❌ | ❌ | ✅ Mandatory |
| Tile image | ✅ as `` img`...` `` literal | ❌ | ✅ for editor-managed tiles |
| Color palette | ✅ in `pxt.json` `palette` array | n/a | ✅ via Assets → Colors |

**Default**: write new sprite art as `` img`...` `` in `.ts` files. Use the web editor (round-tripped via GitHub) for tilemaps, songs, and large animations.

## Effects

```typescript
player.startEffect(effects.confetti, 500)       // ms
effects.confetti.startScreenEffect()
effects.confetti.endScreenEffect()
sprite.destroy(effects.fire, 200)               // destruction effect with duration
```

Built-in effect names: `confetti`, `fire`, `bubbles`, `coolRadial`, `disintegrate`, `halo`, `spray`, `trail`, `warmRadial`, `clouds`, `hearts`, `smiles`, `rings`, `slash`, `splatter`, `star`.
